# Contributing

Issues and focused pull requests are welcome.

1. Open an issue before adding a provider, changing methodology, or substantially expanding the company universe.
2. Use Node.js 24 and install with `npm ci`.
3. Run `npm test` and `npm run build` before submitting a pull request.
4. Add deterministic fixtures and tests for normalization or classification changes.
5. Do not add scrapers for aggregators, social networks, private endpoints, authenticated pages, or sources that prohibit automated collection.
6. Do not commit generated public data, RSS, screenshots, build output, local browser profiles, or dependencies.

Keep claims narrow: a posting is evidence of a published opening, not proof of a hire, revenue growth, or net headcount growth.
