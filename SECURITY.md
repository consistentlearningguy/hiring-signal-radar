# Security policy

Please report vulnerabilities through the repository's private **Security → Report a vulnerability** flow. Do not include secrets, exploit details, or personal information in a public issue.

Supported versions are the current `main` branch and the latest published deployment.

The project has no accounts or runtime backend. Security-sensitive areas still include generated outbound URLs, build dependencies, GitHub Actions permissions, and any future data provider. Source URLs must remain restricted to HTTP(S), and no candidate or authentication data may be collected.
